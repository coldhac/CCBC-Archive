## 答案

`DROPPING FABLES`

## 解析

## 提示

### 1. 我毫无头绪

你需要两个知识：28星宿中天有九野的分类，以及所有科学家实际的名字。他们的名字都经过了某种变化。

### 2. 我的答案有什么用？

你的答案翻译成一个中文汉字后，在经过特定变化后可以成为某个星宿。特别的，这些星宿来自于不同的九野之一。同时，所有的科学家名字也进行了同样的变化。注意对应变化关系时的方向，应当是从“什么都不是”到科学家的真名。

### 3. 我还是弄不明白对应关系，能帮我详细剖析一下这些科学家的名字吗？

丘败梓→丘成桐	= 反义词+并列词；<br>
苏部绿→苏步青	= 同音字+前进列表；<br>
朱晃冠→朱光亚	= 减部首+前进列表；<br>
施零私→施一公	= 前进列表+反义词；<br>
钱二弱→钱三强	= 前进列表+反义词；<br>
赵数瘴→赵九章	= 概括词语+减部首；<br>
吴聿性→吴健雄	= 加部首+概括词语；<br>
杨辰静→杨振宁	= 加部首+并列词；<br>
陈醒体→陈省身	= 同音字+并列词；<br>
周粒唤→周光召	= 概括词语+并列词；<br>
李三电→李四光	= 前进列表+并列词；<br>
华姓辛→华罗庚	= 概括词语+回退列表；<br>
姚时体→姚期智	= 并列词+回退列表；<br>
丁聿北→丁肇中	= 加部首+前进列表。

### 4. 该如何提取

上一步得到的东西可以对应到不同的方位上。你可以通过每个科学家的两种方位，利用旗语得到字母。

### 5. 我觉得小题答案和meta有点对不上，但是由于我剧情一个字都没有看，因此请告诉我是什么机制导致我有这种感觉

你不看狐宝的剧情，狐宝不开心，所以找你要了3000话费买这条，现在听好了：每个分区都有1个小题的答案没有在本区meta中使用！
