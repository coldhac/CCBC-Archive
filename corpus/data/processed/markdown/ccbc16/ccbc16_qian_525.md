# 千字谜子题 525

## 题面

![题图](../../../assets/static.cipherpuzzles.com/static/images/c09785cce6e14ab197d0283f56c90878.webp)

## 答案

`昼`

## 解析

注意到①②③④可以连成一个词，而②代表的是夜，③④代表的是颠倒的过程，因此应该是昼夜颠倒，其中的红字为“？”，则得到“昼”。
