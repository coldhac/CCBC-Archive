# 千字谜子题 512

## 题面

![题图](../../../assets/static.cipherpuzzles.com/static/images/09cc9554d3d04a8192dd45cb5ac30700.webp)

## 答案

`仕`

## 解析

观察到仁和佰之间正好有97个框，所以每个框中的右半部分代表对应位置的数字，即二至一百。红色框的位置对应十一，所以答案是仕。
