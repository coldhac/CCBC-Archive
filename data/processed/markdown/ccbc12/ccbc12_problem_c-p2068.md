# #2068 残缺纸张 - CCBC 12

## 题面

一张撕得还算整齐的纸，很多内容只能看到一半了。

![题图](../../../assets/archive.cipherpuzzles.com/ccbc12/images/c/8b2322f5b63b410789539de21ba7bf11.webp)

## 答案

`ENSUED`

## 解析

题目中的每个单词都被横向切了一半，而每个单词本身减半之后也可以用另一个单词表示（减半之后的单词长度等于上方给出的分母）：

- FORTNIGHT（两周） -> W**E**EK（一周）
- HEXAGRAM（六芒星） -> TRIA**N**GLE（三角形）
- SCHOOL YEAR（学年） -> **S**EMESTER（学期）
- HALF（一半） -> Q**U**ARTER（四分之一）
- OCTAVE（八度） -> TRITON**E**（三全音）
- DIAMETER（直径） -> RA**D**IUS（半径）

按照给出的分子取字母得到答案：**ENSUED**。

## 提示

### 1. 我毫无头绪

这些单词是FORTNIGHT, HEXAGRAM, SCHOOL YEAR, HALF, OCTAVE, DIAMETER。每个单词被撕了一半，那么把每个单词的含义也减半会怎么样呢？
