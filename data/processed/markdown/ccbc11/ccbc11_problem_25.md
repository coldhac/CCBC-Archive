# #25 - CCBC 11

## 题面

这是一个U盘，里面只有一个<a href="../../../assets/archive.cipherpuzzles.com/ccbc11/images/problems/cc55b9501b5d43d195069c05f93e19c1.rar" target="_blank">rar 文件</a>。

## 答案

`TIME LORDS`

## 解析

有趣的文字解谜游戏，流程中可以将灰烬带回前一天了解游戏机制及剧情，look指令可以简写为l，输入enter可直接进入蓝箱子。关键要在电脑中购买螺丝刀传送到第二天，速通的简明攻略如下：

→ search 尸体 
→ read 信用卡 
→ enter 
→ left 
→ turn on 电脑 
→ 对照旗语表解答开机密码tardis 
→ type tardis on 电脑 
→ 购买声波螺丝刀 
→ type 123456787654321 on 电脑 
→ enter 
→ right 
→ l 门 
→ search 邮箱 
→ take 螺丝刀 
→ enter 
→ left
→ search 桌子 
→ fix 手机 with 螺丝刀 
→ take 手机
→ enter 
→ right 
→ l 手机 
→ enter 
→ left 
→ type Joycelin on 保险箱 
→ search 保险箱 
→ take 手枪 
→ enter 
→ right 

通关获得答案。



最后的答案是：**TIME LORDS**。
